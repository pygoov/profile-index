# Profile Index

Профессиональное портфолио в Markdown для людей и AI-агентов. Оно описывает проекты, вклад и компетенции владельца в устойчивой ко времени форме; неизвестные и приватные сведения не публикуются.

Профиль представляет инженера, специализирующегося на архитектуре backend- и асинхронных систем, диалоговых и AI-решениях, интеграциях, инженерных платформах и эксплуатационной надёжности. Основной акцент сделан на личном вкладе, техническом владении и архитектурной эволюции проектов.

## Навигация

- [`index.md`](index.md) — полный индекс проектов и документов о компетенциях.
- [`projects/README.md`](projects/README.md) — правила чтения дерева проектов и формат карточки.
- [`competencies/README.md`](competencies/README.md) — сводное представление профессиональных компетенций.
- [`AGENTS.md`](AGENTS.md) — границы репозитория и маршрутизация процедур для AI-агентов.

## Разделение областей

- `projects/` содержит иерархические карточки проектов; путь каталога задаёт идентичность и родительскую связь узла.
- `competencies/` синтезирует профессиональные возможности владельца на основании проектного опыта и явно отмеченного дополнительного опыта.
- `.agents/skills/` содержит только процедуры чтения и редактирования репозитория; это не перечень профессиональных компетенций.
