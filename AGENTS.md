# Инструкции репозитория

Этот репозиторий — профессиональное портфолио только в Markdown. Идентичность и родительская связь проекта определяются относительным путём его каталога; каждый содержательный каталог в `projects/` содержит `README.md`. `competencies/README.md` — канонический синтез профессиональных компетенций владельца, а `index.md` — полный навигационный индекс.

`.agents/skills/` содержит процедуры для AI-агентов и не относится к профессиональным компетенциям владельца в `competencies/`.

- Для чтения, поиска, обобщения и объяснения содержимого портфолио загрузи `.agents/skills/read-profile-index/SKILL.md`.
- Для добавления, изменения, перемещения или удаления содержимого и навигации загрузи `.agents/skills/edit-profile-index/SKILL.md`; там определены чтение перед правкой и обязательная проверка.
- Не выдумывай факты и не раскрывай работодателей, заказчиков, партнёров, внутренние идентификаторы, указатели на источники, реальные данные, адреса, полезные нагрузки, контакты, учётные данные, секретоподобные значения, непроверенные даты, метрики и результаты.
- Неизвестное опускай. Сохраняй точную атрибуцию вклада и не подразумевай единоличное авторство, текущую занятость, сопровождение или активную разработку.
- Не читай, не выполняй и не изменяй рабочий монорепозиторий. Не читай и не изменяй `IDEA.md`, если владелец явно не изменил эту границу.
- Не добавляй Python, JSON-схемы, канонический JSON, генерируемые экспорты, пакетные окружения, проверки через Makefile или hosted CI.
- Не выполняй commit, stage, push, reset, clean, checkout, stash и не переписывай историю Git без отдельного явного запроса владельца.

Прямая инструкция пользователя имеет приоритет, только если она не требует выдумки, нарушения приватности или пересечения явной границы репозитория.
